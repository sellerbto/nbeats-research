# N-BEATS: Improving Deep Learning for Time Series Forecasting

Research project посвящён исследованию архитектуры **N-BEATS** для прогнозирования временных рядов и проверке гипотез по улучшению её качества.

## Project Overview

N-BEATS — одна из первых архитектур глубокого обучения, сумевших превзойти классические статистические методы на соревновании **M4 Competition**. Цель проекта состояла в том, чтобы:

* воспроизвести базовую реализацию N-BEATS;
* разобраться в архитектуре модели;
* провести контролируемые A/B-эксперименты с собственными модификациями;
* оценить влияние изменений на качество прогнозирования.

## Baseline

В качестве базовой модели использовалась реализация **Generic N-BEATS**.

Исследовались следующие особенности архитектуры:

* residual stacking;
* backcast / forecast blocks;
* fully-connected backbone;
* обучение без специализированных компонентов для временных рядов.

---

## Experiments

### 1. RevIN (Reversible Instance Normalization)

**Гипотеза**

Стандартная нормализация N-BEATS недостаточно хорошо работает с нестационарными временными рядами.

Была реализована обёртка RevIN, выполняющая:

* нормализацию входного окна;
* обучение модели в нормализованном пространстве;
* обратное восстановление масштаба прогноза.

Проводилось парное сравнение:

* Baseline
* N-BEATS + RevIN

для нескольких случайных инициализаций.

---

### 2. Multi-Head N-BEATS

**Гипотеза**

Полноценные ансамбли значительно улучшают качество прогнозирования, но требуют больших вычислительных затрат.

В проекте была реализована более дешёвая альтернатива:

* общий backbone;
* несколько независимых выходных голов;
* разные функции потерь (MAE, MSE, sMAPE);
* усреднение прогнозов на инференсе.

Идея заключалась в снижении дисперсии ошибки без обучения нескольких независимых моделей.

---

## Experimental Protocol

Для всех экспериментов использовались:

* одинаковые train/validation/test splits;
* три различных random seed;
* парное сравнение baseline и модификации;
* оценка на checkpoint с лучшим validation sMAPE.

---

## Results

### RevIN

✅ Показал статистически значимое улучшение на **Hourly** данных M4.

* снижение sMAPE;
* более быстрая сходимость модели;
* воспроизводимый эффект на всех random seed.

На **Monthly** данных улучшение не подтвердилось.

---

### Multi-Head

❌ Гипотеза не подтвердилась.

Несмотря на снижение вычислительной стоимости по сравнению с ансамблем независимых моделей:

* качество не улучшилось;
* отдельная sMAPE-head оказалась не хуже усреднения;
* общий backbone оказался недостаточно универсальным для различных функций потерь.

---

## Key Takeaways

В ходе проекта удалось:

* реализовать архитектуру N-BEATS на PyTorch;
* воспроизвести результаты базовой модели;
* разработать и проверить две исследовательские гипотезы;
* провести воспроизводимые A/B-эксперименты;
* выполнить статистический анализ результатов;
* показать, что RevIN может улучшать качество прогнозирования на нестационарных временных рядах.
